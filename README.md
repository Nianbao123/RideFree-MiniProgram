安大“自由行” (RideFree) - 校园二手车辆租借小程序
项目背景
针对高校内共享出行工具匮乏、个人购车闲置率高的痛点，设计的一款基于 C2C 模式的校园车辆租借微信小程序。

产品演示
🎬 【“安大自由行”小程序demo演示-哔哩哔哩】 https://b23.tv/qAvvbkM

功能模块
我要用车：基于 LBS 地图展示附近可租车辆。

扫码租借：模拟智能硬件扫码，打通云端计时与状态变更。

自动结算：云函数按分钟自动计费，闭环订单流程。

我要出租：车主端入口（Demo 阶段为 UI 占位）。

技术架构
前端：微信小程序原生框架（WXML / WXSS / JS）

后端：微信云开发（云数据库、云函数）

开发模式：产品经理通过 Prompt 定义业务逻辑，借助 AI Agent 辅助生成代码，独立完成全栈开发验证。

体验说明
注：本项目为验证业务闭环的 MVP Demo，硬件交互（智能锁）采用软件扫码模拟实现。
